Tentang Tool Ini

Tool ini membantu kamu membuat link checkout untuk langganan GPT Plus dengan harga regional. Cukup paste session token ChatGPT dan pilih region.

Cara mendapatkan session token:

  1. Login ke chatgpt.com
  2. Buka tab baru, akses chatgpt.com/api/auth/session
  3. Salin seluruh JSON response
  4. Tempel di kolom "Auth Session"
