Kalkulator Validitas Isi (Aiken's V)

Hitung indeks validitas isi instrumen berdasarkan penilaian validator/ahli.

V = ΣS / [ n (c − 1) ] , dengan S = r − lo lo = skor terendah · c = skor tertinggi · n = jumlah validator · r = skor validator
V = validitas isi
S = r − lo
n = jumlah validator
r = skor yang diberikan validator
lo = skor terendah (default 1)
c = skor tertinggi (default 4)
Klik Buat Tabel untuk menyusun ulang tabel sesuai jumlah validator & butir. Mengubah lo/c akan otomatis memperbarui hasil.
Tip: gunakan Tab untuk pindah antar sel. Nilai harus dalam rentang [1, 4].

Kriteria interpretasi (Aiken, 1985)
  • V < 0.4  → validitas rendah
  • 0.4 ≤ V ≤ 0.8 → validitas sedang
  • V > 0.8  → validitas tinggi
