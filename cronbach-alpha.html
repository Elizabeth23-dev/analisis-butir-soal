Kalkulator Reliabilitas Cronbach's Alpha

Hitung reliabilitas instrumen penelitian Anda secara otomatis

📐 Rumus Cronbach's Alpha

α = n⁄(n − 1) × { 1 − ∑ si²⁄st² }
α = indeks reliabilitas  |  n = banyaknya butir pertanyaan  |  ∑ si² = total varians item  |  st² = varians skor total
Nilai α Interpretasi
0,00 ≤ α ≤ 0,20Sedikit reliabel
0,20 < α ≤ 0,40Kurang reliabel
0,40 < α ≤ 0,60Cukup
0,60 < α ≤ 0,80Reliabel
0,80 < α ≤ 1,00Sangat reliabel

Sumber: Imaduddin, Maulani, & Taufik (2022); Sundayana (2018)

📝 Input Data

Tempel data dari Excel atau spreadsheet. Setiap baris = 1 responden, kolom dipisahkan Tab atau koma. Baris pertama bisa berupa header (opsional).
